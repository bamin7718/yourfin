Quên mật khẩu?

Dữ liệu được đồng bộ qua Supabase và lưu bản sao trên máy này để dùng offline.

Dữ liệu được mã hoá đám mây & hỗ trợ ngoại tuyến (Offline)

Chưa kết nối Supabase

Dán thông tin dự án Supabase để dùng ngay trên máy này. Khi deploy, đặt chúng làm biến môi trường thay vì nhập tay.

Lấy ở đâu

  1. Mở supabase.com/dashboard → chọn dự án
  2. Vào Project Settings → API
  3. Chép Project URL và anon public
  4. Chạy supabase/schema.sql trong SQL Editor
